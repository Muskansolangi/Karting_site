# Karting Website

This is a responsive frontend website developed as a practice project for a karting business. The website focuses on a clean layout, responsive design, and an easy user experience.

## Live Demo

https://kart-circuit.netlify.app/

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features

- Responsive layout
- Navigation bar
- Hero section
- About section
- Services section
- Gallery
- Booking section
- Contact section
- Mobile-friendly design
